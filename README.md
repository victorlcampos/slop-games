# 🕹️ slop-games

Games that run entirely in the browser. Each one is **a single HTML file** — no
server, no install, no account.

▶️ **[Play](https://victorlcampos.github.io/slop-games/)**

---

## The catalog

| | Game | What it is | Libs | Network |
|---|---|---|---|---|
| 🐆 | **[Animals vs Monsters](games/animais-vs-monstros)** | Lane defence. The legends took flesh and froze humanity with fear; the animals never heard those stories, so they are immune. 10 stages across Brazil against its folklore. | none | offline |
| ⛷️ | **[SkiFree 3D](games/skifree3d)** | A 3D take on SkiFree from 1991. Race down the mountain dodging trees until the Abominable shows up. | three.js | offline |
| 🚗 | **[World Drive](games/worlddrive)** | Drive down any street in the world. The 3D scenery is built live from real OpenStreetMap data. | three.js | needs network |
| 🦁 | **[Zoo Tycoon](games/zoo-magnata)** | A zoo tycoon with 219 species drawn in code, free-form enclosures and a full economy. | none | offline |

Not one of them ships a single image: sprites, terrain, textures and sound are
all generated by code at load time. Even the 🇧🇷/🇺🇸 flags in the language
picker — the emoji has no glyph on Windows, so they are drawn on a canvas.

**Every game speaks English and Portuguese.** The choice covers the whole
catalog: switching the flag on the index switches it in whatever game you open
next.

## Running locally

```bash
npm install       # once
npm run open      # builds everything and opens the index in a browser
```

The build produces `dist/index.html` (the index) and `dist/<slug>/index.html`
(each game). They all open on a **double click** — no local server.

```bash
npm run build              # build everything
npm run build zoo-magnata  # build one game
npm test                   # opens everything over file:// and checks for JS errors
```

## Adding a game

The house rules — technologies, the build contract, what is not up for
negotiation — live in **[CLAUDE.md](CLAUDE.md)**. The short version: a
self-contained `index.html`, zero CDN, assets generated by code, esbuild as the
bundler.

The index is generated from `games/*/game.json`, so a new game shows up on its
own after a build.

## On a phone

Open **[the catalog](https://victorlcampos.github.io/slop-games/)** and use "Add
to Home Screen" (iOS) or "Install app" (Android). It becomes a single icon with
every game inside — and from inside a game, the exit on the home screen takes
you back to the list.

## Publishing

Push to `main` → GitHub Actions **runs the tests and only publishes if they
pass**. What goes live is the exact artifact that was tested, not a fresh build.
A pull request runs the same tests without publishing. `dist/` is not committed.

## Tests

```bash
npm test               # the kit's unit tests + the floor every game has to clear
npm run test:games     # each game's own test
CI=1 npm test          # reproduces the runner's environment
```
